```md
# MoneyFlow UI

MoneyFlow UI is the Angular frontend for the MoneyFlow Personal Finance Management System.

It provides a user-friendly interface to manage income, expenses, budgets, and financial reports.
```
---

## 🚀 Tech Stack

- Angular 19
- TypeScript
- RxJS
- Angular Material (Planned)
- Chart.js (Planned)

---

## 📌 Features

- ✅ Dashboard Overview
- ✅ Income & Expense Management
- 🚧 Budget Module (In Progress)
- 🚧 Monthly Reports (Planned)
- 🚧 Charts & Analytics (Planned)
